# Conlang

A personal constructed language project. This repository holds the working notes, dictionary, grammar references, translations, and journals that document the language as it evolves.

The language draws heavily on European-language vocabulary and sound changes, with its own morphology (grammatical case, gendered agreement, thematic/athematic verb conjugations) layered on top.

## Structure

- **Conlang Notes/** — The active, version-controlled working notes, written in Markdown and edited in [Obsidian](https://obsidian.md).
  - [Borrowing Words.md](Conlang%20Notes/Borrowing%20Words.md) — Rules for borrowing and adapting words from other European languages.
  - [Verbs.md](Conlang%20Notes/Verbs.md) — Verb morphology: stems, theme vowels, subjunctive, tense, gender, and conjugation classes.
  - [Grammatical Case.md](Conlang%20Notes/Grammatical%20Case.md) — Nominative, accusative, and disjunctive cases with their gender/number morphemes.
  - [Personal Pronouns.md](Conlang%20Notes/Personal%20Pronouns.md) — Personal pronoun system.
  - [Dictionary/](Conlang%20Notes/Dictionary/) — One Markdown file per word, each with definitions, grammatical properties, irregular forms, and etymological inspiration.
- **Conlang Journal/** — A separate Obsidian vault for journal entries written in the conlang.
- **Translations/** — Translation projects (e.g. Biblia, Pokémon).
- **Conlang.keylayout** — A macOS keyboard layout for typing the conlang's special characters.
- **.pages / .numbers files** — Older or long-form reference material maintained in Apple Pages/Numbers:
  - `Grammar.pages`, `Dictionary.pages`, `Lessons.pages`, `Wiki.pages`
  - `Jornal.pages`, `Jurnal.rtf` — earlier journal drafts
  - `Conlang.numbers` — spreadsheet-based reference data

## Working in this repo

The Markdown notes are structured as Obsidian vaults (`Conlang Notes/` and `Conlang Journal/`), so wiki-style `[[links]]` between notes — e.g. between a borrowing rule and the resulting dictionary entry — are used throughout. Opening either folder as a vault in Obsidian is the intended way to browse.
